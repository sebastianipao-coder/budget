# Budget

Web app di budget planning (telefono e computer). I dati restano salvati sul dispositivo (localStorage).

Online: https://sebastianipao-coder.github.io/budget/

Legge automaticamente le giornate lavorate dall'app [Giornate](https://sebastianipao-coder.github.io/giornate/) (stesso dominio, stesso browser) e le usa come entrate previste.
